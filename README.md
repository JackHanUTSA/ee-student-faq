# Electrical Engineering Student FAQ

Step-by-step answers, forms, and contacts for UT San Antonio Electrical Engineering graduate and undergraduate students.

This is a static website: open `index.html` or publish the folder with GitHub Pages.
The content is generated from the department's Word FAQ. To change it, edit the Word file and rebuild
with the department's update tools, then upload the new files here. Do not edit `assets/content.js` by hand.

Questions or corrections: the EE Program Coordinator, Belinda.Guevara@utsa.edu.
